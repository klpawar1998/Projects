# 📋 Dynamic Form Builder

A browser-based **drag-and-drop form builder** built with vanilla JavaScript — no frameworks, no dependencies. Create, customise, and export fully functional HTML forms in seconds.

---

## 🚀 Features

- ➕ **Add fields dynamically** — text inputs, checkboxes, radio buttons, dropdowns, and more
- 🔀 **Reorder fields** — drag and drop to rearrange form elements
- ❌ **Remove fields** on the fly
- ✅ **Client-side validation** — required fields, input type checks
- 📱 **Fully responsive** — works seamlessly on desktop, tablet, and mobile
- 🎨 **Clean UI** — minimal, distraction-free design

---

## 🧰 Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Structure & semantic markup |
| CSS3 | Responsive styling & layout |
| JavaScript (ES6+) | Dynamic behaviour, drag-and-drop, validation |

> No frameworks. No libraries. Pure vanilla JS.

---

## ⚙️ How to Run

No installation needed — just open in a browser.

```bash
# Clone the repo
git clone https://github.com/klpawar1998/Projects.git
cd Projects/Dynamic\ Form\ Builder

# Open in browser
open index.html
```

Or simply double-click `index.html`.

## 🎯 Supported Field Types

| Field Type | Description |
|---|---|

| Textarea | Multi-line text entry |

| Radio Button | Single selection from options |
